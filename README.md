Requires Fabric API, Architectury, and Depression as prerequisites.

Planned: Origins compat, AppleSkin compat.

## 📑 Introduction

Depression-TianTian (the mod) is an addon for the Depression mod (the base mod).

It tweaks parts of the base mod, adds more configurable options, and most importantly—beefs up the diary system. It can also serve as a library mod for other creators.

### 💖 For Players

One of the reasons this mod exists is that I felt the base mod's diary entries were too few and too scripted. So I kinda went overboard and threw in a ton of new diary content.

Beyond that, here's what's new:

- **Enhanced diary generation** — produces richer, more personalized entries based on your daily in-game behavior.
- **More hint messages** — for immersion and that little spark of novelty.
- **More visible somatic symptoms** — like simulating anorexia, making the hunger bar disappear.
- **More configurable options** — disable the personality trait selection screen, tweak the psychiatrist's item prices, and more.
- **Gameplay safeguards** — e.g., prevents closing your eyes while airborne.
- **(Planned) Self-harm to raise mood** — dangerous; repeated self-harm can kill you.
- **More ways to recover mood and mental health**.

### 🗺️ For Other Creators

This mod also serves as a library that makes the base mod's code easier to work with, providing a decent set of events and wrapper classes.

And honestly—while the base mod clearly isn't designed for modpacks—you never know when someone might want to build a pack around it, right?

The diary system has been systematically refactored, making it much easier to add or modify content. If you want to do that, check out the [WIKI](https://github.com/GRAINALCOHOL/depression-tiantian/wiki).
